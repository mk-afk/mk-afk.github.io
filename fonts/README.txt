Fonts in this folder
====================

These are web versions of Latin Modern, the typeface LaTeX uses by default
(the same one the PDF resume is set in).

Latin Modern is by Boguslaw Jackowski and Janusz M. Nowacki (GUST e-foundry),
based on Donald E. Knuth's Computer Modern. Version 2.005.
Originals: https://www.gust.org.pl/projects/e-foundry/latin-modern

Licence: GUST Font License (see GUST-FONT-LICENSE.txt in this folder), which
is the LaTeX Project Public License 1.3c plus a request to rename modified fonts.

What was changed, and by whom
-----------------------------
These files are NOT the original fonts. For this website they were:
  1. cut down to Latin characters (Basic Latin, Latin-1, Latin Extended-A,
     common punctuation, arrows and ligatures), to keep them small;
  2. converted from OpenType (.otf) to WOFF2;
  3. renamed from "LM ..." to "LMWeb ...", as the licence asks of modified fonts.
Kerning, ligatures and the other OpenType features are untouched.
The original authors are not responsible for these versions and do not support them.
